Getting it into Anki

  1. Install Anki if you haven't: the desktop app is free at apps.ankiweb.net. On iPhone use AnkiMobile; on Android use AnkiDroid.
  2. Download the deck using the button above.
  3. On a computer, double-click the file or use File, then Import in Anki. On a phone, open the file and choose Anki when asked which app to use.
  4. Sync with AnkiWeb if you want it on all your devices.

Before you study from it

This deck was made with Claude by a medical student while learning. It may contain mistakes or things that have changed since. Check anything important against current guidelines and your own course, and never use it to make decisions about a real patient.
